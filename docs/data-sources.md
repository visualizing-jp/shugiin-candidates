# データソース

「衆議院選挙で、誰が立候補し、誰が当選したか」のデータソース調査と、データ層の設計方針。
調査日: 2026-09-26。URL と表の中身は取得して確認済み。

## 1. 結論

一次情報源は総務省「衆議院議員総選挙・最高裁判所裁判官国民審査結果調」（兄弟サイト election-shugiin-timeseries と同じ）。
各回の結果ページにある、候補者数と当選人数の次の6表を使う。

| id | 表 | 次元 |
| --- | --- | --- |
| `candParty` | 届出政党等別男女別新前元別候補者数（小選挙区、比例代表） | 党 × 制度 × 新前元 × 男女。比例代表には重複立候補者数（内書） |
| `candPref` | 都道府県別届出政党等別新前元別候補者数（小選挙区） | 都道府県 × 党 × 新前元。定数の列 |
| `candAge` | 都道府県別年齢段階別候補者数（小選挙区） | 都道府県 × 年齢段階（25〜29歳 … 70歳以上の10段階） |
| `winParty` | 届出政党等別男女別新前元別当選人数（小選挙区、比例代表） | 党 × 制度 × 新前元 × 男女 |
| `winPref` | 都道府県別届出政党等別新前元別当選人数（小選挙区） | 都道府県 × 党 × 新前元。定数の列 |
| `winAge` | 都道府県別年齢段階別当選人数（小選挙区） | 都道府県 × 年齢段階 |

範囲は第44〜51回（2005–2026）。6表がどの回にもそろうのは第44回から。

- 第41〜43回: 総務省サイトに回ごとのページがない。第49回確定結果調の推移表に制度別の候補者数・女性・新前元・年齢段階（全国のみ）はあるが、党 × 男女や都道府県別はないので載せない。
- 年齢段階別の表は小選挙区だけで、党派別・男女別の内訳はない。都道府県別の表も小選挙区だけで、男女別の内訳はない。

出典表記: 総務省「衆議院議員総選挙・最高裁判所裁判官国民審査結果調」。

### 確定と速報

各回のページはどの回も「速報結果」の見出しで公開されている。
[第49回確定結果調](https://www.soumu.go.jp/main_content/000930924.pdf)の推移表（p.9「新前元別候補者数」、pp.31–33「新前元別当選人数」「新前元別当選率」、p.33「女性の当選率」）には第44〜49回の制度別の新人・前議員・元議員・女性の候補者数と当選人数がある。
結果ページの表から組み立てた値をこれと `npm run verify` で突き合わせ、次の1件を除いて一致を確認した。このため第44〜49回を「確定」、確定結果が公表されていない第50・51回を「速報」とする。

- 第49回の小選挙区の当選人は、結果ページの表が新人40・前議員238、確定結果調が新人41・前議員237。確定結果調の「党派別新前元別当選人数に関する調」（p.158）で東京都の立憲民主党が新人2・前議員6、結果ページの表は新人1・前議員7。候補者数の表は確定値と一致している。
  確定結果調の「党派別男女別当選人数に関する調」は新前元と掛け合わせていないので、この1人の男女は表からは決まらない。推測で直さず結果ページの表のまま載せ、画面の注記で断る。`npm run verify` は差がちょうどこの1人分であることを確かめる。
- 第48回小選挙区の女性候補者数は、同じ確定結果調のなかで p.8「女性候補者数」の表が157人、p.33「女性の当選率」の表が158人（全体も209人と210人）。結果ページの表は157人で、p.8 と一致する。

## 3. 読み方の決まり

表の組み方は回と形式で揺れるので、党の列は党名ではなく小見出し（男・女・計、新・前・元・計）の位置から決め、党名はその上の見出しをつなげて読む（[`src/lib/parse/tables.ts`](../src/lib/parse/tables.ts)）。

- 党名は各回の届出名称のまま。全角英数は半角に寄せ、空白と注記（※1）を除く。2行に折られた党名はつなぐ。兄弟サイトと同じ決まりなので、党名が同じ文字列になる。
- 「その他」「本人・推薦届出」は、政党等所属・無所属・小計の3列をくくる上位の見出しとして外す。
- 「政党等所属」（本人・推薦届出で立候補した、政党その他の政治団体に属する候補）は、得票の表の呼び方に合わせて「諸派」とする。第51回は表でも「諸派」。
- 「小計」（諸派 + 無所属）は読まない。「合計」「計」は突き合わせにだけ使う。
- 空欄・ダッシュは 0。
- 表の中の「計」（男 + 女、新 + 前 + 元）は読むたびに内訳の和と突き合わせ、合わなければ止める。
- 候補者の「全体」は結果調の「候補者数計」（小選挙区 + 比例代表 − 重複立候補者）。当選人の「全体」は「合計」（重複しない）。
- 年齢段階は画面で10歳刻み（20代 = 25〜29歳、30代、40代、50代、60代、70歳以上）にまとめる。

### 第44回の PDF

`pdftotext -bbox`（poppler）で語ごとの位置を取り、Excel と同じ行 × 列のセルに組み直してから同じ解析器に通す（[`src/lib/parse/pdf.ts`](../src/lib/parse/pdf.ts)）。

- 列は、小見出しの最も多い行の小見出し1つにつき1列。見出しの「小 計」「合 計」の字を拾わないため。年齢段階の表だけは「計」が1段上にあり右端に付くので、その行より右の小見出しを足す。年齢段階は上下2段の見出し（25歳／29歳）のうち上の段を列にする。
- 数値は列の右端に揃っているので、数値の右端より左に右端がある最後の小見出しをその列とする。文字は中心が最も近い小見出しの列に置く。
- 重複立候補者数の「( 73)」は「(」と「73)」の2語に分かれるので、括弧を外す。

## 4. 突き合わせ（`npm run verify`）

- 党派別: 合計列 = 党の和。全体 = 小選挙区 + 比例代表 − 重複立候補者（当選人は重複なし）。
- 都道府県別: 計の行 = 都道府県の和。党ごとの計の行 = 党派別の表の小選挙区。都道府県の合計 = 党の和。
- 年齢段階別: 計の行 = 都道府県の和。都道府県ごとの人数 = 都道府県別の表の合計。
- 定数: 都道府県の小選挙区の数の和 = 小選挙区の定数。小選挙区・比例代表の当選人 = 定数。都道府県の当選人 = その都道府県の小選挙区の数。
- 確定値: 第44〜49回の制度別の新人・前議員・元議員・女性の人数（§2）。

## 5. 配信データ

`npm run data` が `data/normalized/*.json` と `data/palette.json` だけを入力に、`public/data/` に書き出す。

| ファイル | 次元 | 値 |
| --- | --- | --- |
| `national.json` | 候補者/当選者 × 制度（小選挙区・比例代表・全体）× 党 × 回 | 新前元 × 男女の人数 |
| `pref.json` | 候補者/当選者 × 党 × 回 × 都道府県、候補者/当選者 × 回 × 都道府県 × 年齢段階 | 人数。小選挙区の数 |
| `palette.json` | 党 | 色相 |

### 党の色

党の色相は兄弟サイトが全国の得票から決めたもの（election-shugiin-timeseries の `public/data/palette.json`）を `data/palette.json` に写して使う。両サイトで同じ党が同じ色になる。
色相のない党があれば `npm run data` が止まる。兄弟サイトの配色が変わったら写し直す。
